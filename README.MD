# KDE Bot Download 3.8.2

ดับเบิลคลิก **KDE Bot Download V3.lnk** เพื่อเปิดโปรแกรมภาษาไทย

| โฟลเดอร์ | ใช้สำหรับ |
|---|---|
| **Program** | โปรแกรมรุ่นที่ใช้งานอยู่ |
| **Development** | โค้ด เครื่องมือทดสอบ และเอกสาร |
| **Archive** | รุ่นก่อนหน้า และหลักฐานการสร้าง/ทดสอบ |

ย้ายหรือแจกจ่ายโปรแกรมโดยนำ **Program ทั้งโฟลเดอร์** ไปด้วย

ไฟล์ดาวน์โหลด: `\\10.0.0.243\pgp-data$` → คัดลอกไป `\\10.0.0.97\Z KDE Bot`

ประวัติ: `\\10.0.0.97\Z Log Bot\KDE Log Bot`

บัญชีและรหัสผ่านยังเก็บแยกตามผู้ใช้ Windows โปรแกรมไม่ย้ายไฟล์ดาวน์โหลดหรือประวัติเข้ามาในโฟลเดอร์นี้

- [คู่มือใช้งาน](Development/docs/QUICK_START.md)
- [รายละเอียดสำหรับผู้พัฒนา](Development/README.MD)
- [รายการเปลี่ยนแปลงและฟังก์ชัน](Development/docs/ARCHITECTURE.md)
