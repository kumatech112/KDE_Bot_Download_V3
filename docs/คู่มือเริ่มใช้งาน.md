# คู่มือ KDE Bot Download V3

## เครื่องใหม่ เช่น 10.0.0.97

1. เปิด KDE Bot Download V3.exe จากโฟลเดอร์ portable
2. เปิดแท็บ **ตั้งค่า** แล้วกรอกบัญชี/รหัสผ่าน KDE Pre และ Post ของ Windows user ที่จะใช้งาน
3. หรือเลือก **นำเข้าการตั้งค่าเดิม** แล้วเลือก config.json หรือ config\settings.json ของ KDE เดิม
4. ถ้ารหัสผ่านเดิมอ่านไม่ได้ โปรแกรมยังเปิดได้และจะแจ้งให้กรอกรหัสผ่านใหม่ ค่าปลายทางและกฎเดิมยังนำเข้าได้
5. ตรวจที่เก็บไฟล์ โหมดทั้งสองที่/เฉพาะเดิม/เฉพาะใหม่ และโฟลเดอร์ Log แล้วบันทึก
6. กด **ตรวจสิทธิ์ / Browser** เพื่อตรวจการเขียนด้วย Windows user เครื่องนี้
7. ตั้ง Outlook desktop ให้เห็น mailbox ที่กำหนด แล้วกด **ตรวจอีเมล**
8. เลือก **นำเข้าประวัติดาวน์โหลด** ถ้าต้องการนำ state.json หรือ _state\kde.json เดิมเข้ามา ต้องหยุด KDE เดิมก่อนใช้โปรแกรมใหม่จริง
9. กด **ตรวจหนึ่งครั้ง** เพื่อตรวจงานจริง เมื่อผลถูกต้องจึงใช้ **ตรวจอัตโนมัติ**

ค่าตั้งต้นและรหัสผ่านเก็บที่ **%LOCALAPPDATA%\KDE Bot Download V3\settings.json**
รหัสผ่านเข้ารหัสด้วย Windows DPAPI ของ user เครื่องนั้น ไม่สามารถนำไฟล์รหัสผ่านไปใช้กับ user/เครื่องอื่นโดยตรง
ไม่ต้องใช้รหัสผ่าน Windows เป็นรหัส KDE

## ผลการทำงาน

- **ขั้นตอน** แสดง 1–8 พร้อมสถานะปัจจุบันและสาเหตุ
- **Complete** แสดงไฟล์ที่ดาวน์โหลด/คัดลอกและตรวจครบปลายทางที่เลือก
- **Error** แสดงปัญหา พร้อมขั้นตอน เช่น Login ไม่ผ่าน, Download timeout, คัดลอกไม่มีสิทธิ์
- **ข้าม** แสดงไฟล์ที่ตรวจ SHA-256 แล้วมีครบ ไม่แสดงเป็น Error
- ดับเบิลคลิกผลเพื่อดูรายละเอียด หรือคัดลอกรายละเอียดที่เลือก
- ใช้ **ลองคัดลอกที่ค้าง** เมื่อแก้สิทธิ์/เครือข่ายแล้ว ต้นฉบับที่มีอยู่จะถูกนำมาคัดลอกโดยไม่ดาวน์โหลดซ้ำ
- ใช้ **โหลดประวัติ CSV** เพื่อแสดงผลล่าสุดจาก log 3 เดือนล่าสุด สูงสุด 2,000 รายการ
- ไฟล์ที่มีชื่อเทียบเท่าแต่เนื้อหาขัดแย้งจะค้างให้ตรวจสอบ โปรแกรมไม่เขียนทับ

## โฟลเดอร์ Log

ใช้ **\\10.0.0.97\Z Log\Log Bot KDE**

- KDE_Log_YYYY-MM.csv: บันทึกผลที่เปลี่ยนไป เปิดอ่านด้วย Excel ได้ ไม่เก็บรหัสผ่าน
- KDE_State.json: ประวัติและสถานะคัดลอกค้าง ใช้ร่วมกันระหว่างเครื่อง
- .kde.lock: ล็อกงาน ใช้ไฟล์เดิม เครื่องอื่นไม่สามารถรัน KDE พร้อมกันได้

อย่าลบประวัติกลางเพื่อแก้ปัญหาสิทธิ์ เพราะประวัติใช้ติดตามงานที่คัดลอกยังไม่ครบ
ถ้าอ่าน/เขียนโฟลเดอร์ Log ไม่ได้ โปรแกรมจะไม่เริ่มงานและแสดงข้อผิดพลาด
โฟลเดอร์ปลายทางต้องมีอยู่และ Windows user ต้องเขียนได้ โปรแกรมไม่สร้าง share หรือเปลี่ยนสิทธิ์ Windows

## การเปิดจากเครื่องอื่น

ใช้ EXE ชุดเดียวกันได้ แต่ต้องตั้งค่าบัญชี/Outlook ของแต่ละเครื่อง
เครื่องที่ดับเบิลคลิก EXE เป็นเครื่องรันงาน แม้ EXE อยู่บน network share
ค่าการตั้งค่าแยกตาม Windows user; เครื่องทั้งหมดที่ใช้ร่วมกันควรเลือกโฟลเดอร์ Log เดียวกันเพื่อใช้ล็อกและประวัติร่วม

## ปุ่มหยุด

หยุดหลังการดาวน์โหลด/คัดลอกปัจจุบันและขั้นตอน Logout จบ
เมื่อสั่งปิดหน้าต่างขณะทำงาน โปรแกรมจะรอ cleanup ก่อนปิด

## การส่งขึ้น GitHub

เก็บเฉพาะ source, tests, build tools, คู่มือ และไอคอน
ไม่เก็บ settings จริง รหัสผ่าน ประวัติ Log หรือ portable binary ใน Git
