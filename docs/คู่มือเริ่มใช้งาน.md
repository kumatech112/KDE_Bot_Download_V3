# KDE Bot Download V3 — 3.1.2

## ตั้งค่าเครื่องที่จะรัน

1. ดับเบิลคลิก KDE Bot Download V3.exe ในโฟลเดอร์ portable
2. ในแท็บตั้งค่า กรอกบัญชี/รหัสผ่าน Pre/Post ของ Windows user ที่จะรัน หรือนำเข้าการตั้งค่าเดิม
3. รหัสผ่านจากเครื่องอื่นอาจถอดรหัสไม่ได้ ให้กรอกใหม่ โปรแกรมยังเปิดหน้าตั้งค่าได้
4. เลือกเก็บทั้งสองที่ / เฉพาะเดิม / เฉพาะใหม่ แล้วตรวจตำแหน่งก่อนบันทึก
5. เปิด Outlook desktop และตรวจว่ามี mailbox ที่ตั้งไว้บนเครื่องนี้
6. กด **ตรวจสิทธิ์ / Browser** และ **ตรวจอีเมล** ปุ่มสองนี้ไม่ Login KDE
7. กด **เฝ้ารออีเมล** เพื่อรอเมลต่อเนื่อง หรือ **ตรวจเมลและทำคิวครั้งเดียว** เพื่อทำเฉพาะคิวที่พบแล้วหยุด

เครื่องที่เปิด EXE เป็นเครื่องรัน แม้ EXE อยู่บน network share ต้องมีสิทธิ์ปลายทาง/Log และ Outlook profile ของเครื่องนั้น
รหัสผ่านเก็บด้วย Windows DPAPI ใน %LOCALAPPDATA%\KDE Bot Download V3 ไม่เก็บบน GitHub

## ขั้นตอนใหม่

1. อ่าน Outlook ในเครื่องทุก 15 วินาที โดยไม่ Login KDE ขณะไม่มีคิวเมล
2. เมลที่ยังไม่ได้อ่านและตรงกฎเข้าคิว หน่วง 3 นาทีตั้งแต่พบครั้งแรก เมลเดิมที่ยังไม่เคยทำก็เข้าคิวได้
3. Pre/Post ทำงานพร้อมกันได้ด้วย Browser แยก Session/cookie บัญชีที่ไม่มีงานจะไม่ Login
4. เมลที่ระบุ Pre/Post หรือรหัสบัญชีชัดเจน ใช้บัญชีที่ตรงกัน เมลที่ระบุด้านไม่ได้ตรวจทั้งสองบัญชีที่เปิด
5. ค้นหาไฟล์ด้วยกฎชื่อ วันที่ รหัสบัญชี และไฟล์แบ่งส่วนเดิม
6. ไม่พบ/ดาวน์โหลดไม่สำเร็จ: Logout และเปิด Session ใหม่อีก 1 ครั้ง รวมครั้งแรกแล้วไม่เกิน **2 ครั้ง**
7. Login ไม่สำเร็จ: ปิด Session แล้วรอ **5 นาที** ก่อนครั้งที่สอง เมลใหม่ของบัญชีเดียวกันต้องรอ cooldown ด้วย
8. ครบ 2 ครั้งยังไม่สำเร็จ: แสดง Error และหยุดเมลนั้น ไม่วน Login ต่อเอง
9. เมลสำเร็จไม่ทำซ้ำแม้ยัง unread หรือเปิดโปรแกรมใหม่ คิว/จำนวนครั้งเก็บในประวัติกลาง

แท็บ **คิวอีเมล** แสดงงานที่รอเวลา
Complete/Error ระบุขั้นตอน ชื่อไฟล์ สาเหตุ และปลายทาง ปรับสถานะรายการเดิมแทนการเพิ่มชื่อซ้ำทุกครั้ง

## ประวัติการทำงาน

แท็บแรก **ประวัติการทำงาน** แสดงเหตุการณ์ตามเวลา พร้อมบัญชี การทำงาน ผล ชื่อไฟล์/อีเมล และรายละเอียด
ตัวอย่าง: พบเมล → รอ 3 นาที → Login → ค้นหา → ไม่พบไฟล์ → Logout → Login ใหม่ → ดาวน์โหลด → คัดลอกสำเร็จ
ข้อผิดพลาดเดิมยังอยู่ในประวัติหลังแก้สำเร็จ ส่วน Error แสดงเฉพาะผลปัจจุบัน

- กด **โหลดประวัติย้อนหลัง** เพื่ออ่าน CSV 3 เดือนล่าสุด แสดงล่าสุดไม่เกิน 2,000 รายการ ประวัติเต็มยังอยู่ใน CSV
- เมื่อเครื่องมีการตั้งค่าแล้ว โปรแกรมโหลดประวัติเมื่อเปิด โดยไม่ Login หรือดาวน์โหลด
- ค้นหาด้วยชื่อไฟล์ บัญชี สาเหตุ การทำงาน ผล หรือปลายทางจากช่องค้นหาด้านบน
- ดับเบิลคลิกรายการเพื่อดูปลายทาง รอบงาน เครื่องที่รัน และ SHA-256 หรือกดคัดลอกรายการที่เลือก
- เอาเครื่องหมาย **เลื่อนไปรายการล่าสุด** ออกเมื่อต้องการอ่านรายการเก่าระหว่างทำงาน

ใช้ CSV เดือนละไฟล์เดิม บันทึกเฉพาะเหตุการณ์งานที่มีความหมาย ไม่เพิ่มบรรทัดทุกครั้งที่อ่านเมลแล้วไม่พบงาน
CSV จากเวอร์ชันก่อนมีเฉพาะเหตุการณ์ที่เคยบันทึกไว้ โปรแกรมไม่สร้างประวัติ Login/ค้นหาในอดีตขึ้นมาเอง

## Outlook แจ้ง Condition is not valid

3.1.2 แก้การนำตัวกรองเมลไปใช้กับโฟลเดอร์ **บันทึกย่อ / Notes** และโฟลเดอร์ชนิดอื่นที่ไม่ใช่อีเมล
โปรแกรมยังตรวจโฟลเดอร์อีเมลย่อย และตรวจว่าแต่ละรายการเป็นเมลก่อนอ่านชื่อ/ไฟล์แนบ
หากตัวกรอง UnRead ใช้ไม่ได้ในโฟลเดอร์เมล จะตรวจสถานะทีละรายการภายใน **จำนวนอีเมลสูงสุดต่อโฟลเดอร์** ที่ตั้งไว้
รายการ **แจ้งข้อมูล** ระบุว่าใช้วิธีสำรอง ไม่ถือเป็น Error หากการอ่านเมลสำเร็จ และไม่เปลี่ยนสถานะ read/unread
โฟลเดอร์เมลที่เข้าถึงไม่ได้จริงยังแสดง Error

ปิดโปรแกรมเดิม แล้วเปิด 3.1.2 จากโฟลเดอร์ portable กด **ตรวจอีเมล** ก่อนกดเฝ้ารออีเมล
เมื่ออ่านสำเร็จ Error ปัจจุบันของการตรวจเมลจะหาย ประวัติข้อผิดพลาดเดิมยังอยู่ ไม่ต้องลบ Log หรือเริ่มตั้งค่าใหม่

## ไฟล์และ Log

- เดิม: \\10.0.0.243\pgp-data$
- ใหม่: \\10.0.0.97\Z Bot KDE
- Log: \\10.0.0.97\Z Log\Log Bot KDE

เก็บทั้งสองที่ = ดาวน์โหลดครั้งเดียวแล้วคัดลอก ตรวจ SHA-256 ทุกปลายทาง ไฟล์เนื้อหาขัดแย้งจะรายงานให้ตรวจสอบ
มีต้นฉบับแล้วแต่คัดลอกไม่ได้ ใช้ **ลองคัดลอกที่ค้าง** โดยไม่ Login หรือดาวน์โหลดซ้ำ
คิวครบ 2 ครั้งแล้ว ใช้ **ลองเมลที่ผิดพลาดใหม่** หลังแก้สาเหตุ ปุ่มนี้เริ่มรอบใหม่อย่างชัดเจน หน่วง 3 นาที ให้ 2 ครั้งใหม่ และเก็บจำนวนครั้งสะสมไว้

Log มี CSV เดือนละไฟล์, KDE_State.json รวมประวัติ/คิว และ .kde.lock หนึ่งไฟล์ ไม่มีโฟลเดอร์แยกตามรอบ
ทุกเครื่องต้องใช้ Log เดียวกันเพื่อป้องกันงานซ้ำ มีเครื่องเฝ้าเมล/ทำงานได้หนึ่งเครื่อง แต่ภายในเครื่องนั้นทำสองบัญชีพร้อมกันได้

## หยุดและเปลี่ยนเวอร์ชัน

หยุดยกเลิกการรอ และรอการดาวน์โหลด/คัดลอกปัจจุบันพร้อม Logout ก่อนปิด
คิวที่ถูกขัดจังหวะเก็บจำนวนครั้งเดิม และรอ 5 นาทีก่อน Session ใหม่
3.1.2 ใช้การตั้งค่า/ประวัติ V3 เดิม และแก้การสแกนชนิดโฟลเดอร์ Outlook
โปรแกรมพร้อมใช้งานอยู่ใน portable โฟลเดอร์เดียว ต้องเก็บ _internal คู่ EXE

การตรวจ offline ไม่ยืนยัน Outlook, สิทธิ์ของ Windows user และ KDE จริงบน 10.0.0.97 ให้ตรวจปุ่มวินิจฉัยบนเครื่องที่จะรันก่อนเริ่มเฝ้าเมล
