# คู่มือ KDE Bot Download 3.8.1

เปิด **KDE Bot Download V3.exe** และเก็บโฟลเดอร์ **_internal** ไว้ข้างโปรแกรม ไม่ต้องติดตั้ง Python หรือ OCR บนเครื่องใช้งาน

## ตั้งค่าครั้งแรก

1. เปิด Outlook แบบคลาสสิกบนเครื่องที่จะใช้งาน ให้เห็นกล่องเมล **data@tradeconnection.co.th**
2. เข้า **ตั้งค่า → บัญชี** กรอกกล่องเมลและชื่อผู้ใช้/รหัสผ่าน Pre / Post
3. ใน **จัดเก็บ** เลือกโฟลเดอร์ .97, .243 และประวัติ พร้อมโหมดการจัดเก็บ
4. กด **บันทึก** เพื่อเก็บค่าอย่างเดียว หรือ **บันทึกและเริ่ม** เพื่อเริ่มติดตามเมลด้วย

หยุดการทำงานก่อนแก้ไขการตั้งค่า รหัสผ่านยังเข้ารหัสสำหรับผู้ใช้ Windows นี้

## ตัวเลือกเพิ่มเติม

เวลาใช้ **HH:MM** แบบ 24 ชั่วโมงตามประเทศไทย หน่วยช่วงรอเป็น **วินาที** ค่าที่บันทึกจะไม่กลับไปเป็นค่าเริ่มต้นเอง งานที่เข้าคิวแล้วเก็บเวลานัดหมายเดิมไว้ ค่าที่เปลี่ยนใช้กับการจัดรอบถัดไป

ปิด **พักติดตามตามเวลา** เพื่อให้ติดตามต่อเนื่อง ตัวเลือกนี้แยกจาก **ลบไฟล์อัตโนมัติ** หากปิด **เริ่มติดตามเมื่อเปิดโปรแกรม** ให้กดเริ่มด้วยตนเอง การกด **บันทึกและเริ่ม** เริ่มได้เสมอ

หากเลือก Chrome/Edge เอง โปรแกรมจะใช้ไฟล์ที่เลือก หากเว้นว่างและซ่อนเบราว์เซอร์จะใช้ตัวที่รวมมา หากแสดงหน้าต่างต้องมี Chrome หรือ Edge บนเครื่อง

ค่าเริ่มต้น:

- คัดลอกและตรวจไฟล์ที่มีแล้ว: `\\10.0.0.97\Z KDE Bot`
- ดาวน์โหลดก่อนคัดลอก: `\\10.0.0.243\pgp-data$`
- ประวัติและสถานะ: `\\10.0.0.97\Z Log Bot\KDE Log Bot`

ต้องมีโฟลเดอร์ปลายทางอยู่ก่อน โปรแกรมไม่สร้างโฟลเดอร์ย่อยหรือไฟล์ทดสอบสิทธิ์ในปลายทางธุรกิจ

## ลบไฟล์อัตโนมัติ (ค่าเริ่มต้น 22:00)

เปิด EXE รุ่นใหม่นี้ที่เครื่อง **.97 หนึ่งครั้ง** โปรแกรมใช้ตัวจับเวลาในตัวเอง ไม่ต้องตั้ง Task Scheduler เลือก **เริ่มพร้อม Windows** เพื่อเปิด KDE เบื้องหลังเมื่อเข้าสู่ Windows ดูผลการตั้งค่าที่แท็บ **ตั้งค่า** โปรแกรมไม่ขอรหัสผ่าน Windows หรือสิทธิ์ผู้ดูแลระบบ

กด **X** เพื่อซ่อนหน้าต่างไว้ในถาดระบบ โปรแกรมยังทำงาน คลิกไอคอน KDE หรือเปิด EXE อีกครั้งเพื่อแสดงหน้าต่างเดิมและเริ่มติดตามเมล หากต้องการหยุดโปรแกรมทั้งหมด ให้เลือก **ออกจากโปรแกรมทั้งหมด** จากเมนูคลิกขวาที่ไอคอน KDE หรือเมนูเครื่องมือ

ค่าเริ่มต้นคือ **พักและลบ 22:00 / ติดตามต่อ 05:00 ตามเวลาไทย** ปรับได้ในหมวดเวลา โปรแกรมรอให้งานบัญชีปัจจุบันจบและออกจากระบบก่อนลบไฟล์ เมื่อถึงเวลาเริ่มติดตามจะทำงานต่อโดยไม่เปิดหน้าต่าง หรือเริ่มก่อนเวลาได้โดยเปิด KDE ด้วยตนเองเมื่อเปิดตัวเลือกเริ่มติดตามอัตโนมัติ การเปิดหน้าต่างไม่บังคับเปิดเว็บทันที ยังคงใช้เมลเป็นตัวเริ่มงานและหน่วงตามที่ตั้งไว้

ต้องคง KDE ไว้เบื้องหลังและให้เครื่องเปิดอยู่ ไม่พักเครื่อง และ Windows ยังลงชื่อเข้าใช้ ล็อกหน้าจอได้ หากเลือกออกจากโปรแกรมทั้งหมด ปิดเครื่อง หรือออกจาก Windows จะไม่สามารถลบหรือเริ่มเวลา 05:00 ได้ การเปิดโปรแกรมหลัง 22:00 ไม่ลบย้อนหลัง และวันใหม่ไม่โหลดไฟล์ของวันก่อนกลับมา

โปรแกรมพยายามยกเลิกเฉพาะงานตั้งเวลา KDE เดิมของผู้ใช้นี้ ถ้าระบบไม่อนุญาตให้ยกเลิก คำสั่งเดิมใน EXE รุ่นนี้จะออกโดยไม่ลบไฟล์ ตัวจับเวลาใหม่ทำงานได้โดยไม่พึ่งบริการ Task Scheduler

ลบเฉพาะไฟล์ที่อยู่ชั้นนอกของทั้ง `\\10.0.0.243\pgp-data$` และ `\\10.0.0.97\Z KDE Bot` แม้เลือกดาวน์โหลดเก็บ .97 อย่างเดียว เก็บ **ทุกโฟลเดอร์และทุกไฟล์ข้างใน** รวม `03 Check`, `Checked`, `Check` และโฟลเดอร์อื่น ไม่เปิดเข้าไปลบและไม่ตามลิงก์

เมื่อถึงเวลา หากมีงานดาวน์โหลดจะรอให้งานบัญชีปัจจุบันบันทึกไฟล์และออกจากระบบเสร็จก่อน ไม่ลบระหว่างเขียนไฟล์ ตรวจผลใน **ประวัติการทำงาน → ลบไฟล์ 22:00** จะระบุไฟล์และปลายทางที่ลบไม่ได้ ไฟล์ที่ล็อกหรือไม่มีสิทธิ์ลบยังคงอยู่ ไม่มีการเปลี่ยนสิทธิ์หรือบังคับลบ

ชื่อไฟล์ที่ถูกลบตามรอบนี้จะถูกจำไว้ **ไม่ดาวน์โหลดหรือบันทึกกลับมาอีกในวันเดียวกัน** แม้มีเมลใหม่หรือปิดเปิดโปรแกรมใหม่ ไฟล์ใหม่ที่ยังไม่ถูกลบ และไฟล์วันที่วันถัดไปยังทำงานตามปกติ

ยกเลิกการลบที่ **ตั้งค่า → เวลา → ลบไฟล์อัตโนมัติ** แล้วกด **บันทึก** การกด **หยุด** หยุดเฉพาะการติดตามเมล ตัวจับเวลาตามที่ตั้งไว้ยังทำงาน

## วิธีทำงาน

**เมลใหม่ → รอ 4 นาที 30 วินาที → Pre → ออกจากระบบ → Post → ออกจากระบบ → รอเมลใหม่**

โปรแกรมตรวจเมลขาเข้าของกล่อง data รวมเมลที่อ่านแล้ว โดยอ่านเฉพาะรหัสเมลและเวลาที่รับ ไม่ใช้หัวข้อ เนื้อหา ชื่อไฟล์แนบ หรือ OCR มาเลือกไฟล์ และไม่แก้ไขสถานะอ่านเมล

ตรวจ Outlook ทุก 15 วินาทีตามค่าเริ่มต้น เวลารอ 4 นาที 30 วินาทีเริ่มเมื่อโปรแกรมพบเมล ไม่ใช่เวลาที่เซิร์ฟเวอร์รับเมล เมลที่เข้ามาในหน้าต่างรอเดียวกันใช้เวลานัดหมายร่วมกัน

ตรวจทุกโฟลเดอร์ขาเข้าของกล่อง data รวมเมลที่กฎ Outlook ย้ายไปโฟลเดอร์ย่อย ไม่ใช้ค่าจำกัดโฟลเดอร์จากรุ่นเก่า ไม่ตรวจโฟลเดอร์ส่งแล้ว แบบร่าง ขาออก ถังขยะ หรือเมลขยะ หน้าหลักแสดงเวลาตรวจเมลล่าสุด จำนวนเมลวันนี้ และเวลานับถอยหลังก่อนดาวน์โหลด หากอ่านเมลได้เพียงบางโฟลเดอร์จะแจ้งเตือนพร้อมรับเมลจากโฟลเดอร์ที่อ่านได้ต่อไป

แต่ละรอบเปิดใช้บัญชีทีละบัญชี ไม่มีสองบัญชีเปิดพร้อมกัน ตั้งจำนวนแถวบนเว็บเป็น **30 รายการต่อหน้า** ดาวน์โหลดไฟล์ของวันนี้ในหน้าปัจจุบันให้เสร็จก่อนจึงไปหน้าถัดไป ไม่ต้องอ่านทุกหน้าก่อนเริ่มโหลด

เรียงคอลัมน์วันเวลาจากใหม่ไปเก่าเมื่อเว็บมีปุ่มเรียง และหยุดเมื่อถึงไฟล์วันที่เก่ากว่าวันนี้ ไม่เปิดหน้าประวัติย้อนหลังต่อ หากเว็บไม่มีปุ่มเรียงต้องแสดงวันที่ใหม่ก่อนอยู่แล้ว หากตรวจพบวันที่สลับลำดับจะหยุดและแจ้งให้เรียงวันที่ก่อน เพื่อไม่ข้ามไฟล์ของวันนี้โดยเดา

ดูวันที่จากคอลัมน์ **วัน เวลา** ของ KDE เช่น `16/10/2026 16:15:26` เทียบกับวันที่ปัจจุบันในประเทศไทย ไฟล์ของวันก่อน วันถัดไป หรือวันที่อ่านไม่ได้จะถูกข้าม ไม่เดาวันที่จากชื่อไฟล์

ประวัติแสดงหน้าที่กำลังทำ จำนวนดาวน์โหลด จำนวนที่มีไฟล์แล้ว จำนวนต่างวัน/วันที่ไม่ชัดเจน และข้อผิดพลาด หากหน้าเว็บค้าง ไม่เปลี่ยน หรือแสดงหน้าเดิมซ้ำ โปรแกรมหยุดงานบัญชีนั้นและเก็บไฟล์ที่โหลดสำเร็จไว้แล้ว

## เมื่อเข้าสู่ระบบไม่ได้

ถ้าบัญชีมีผู้อื่นใช้งาน หรือเข้าสู่ระบบ/เชื่อมต่อไม่ได้ โปรแกรมรอ **1 นาที** แล้วลองบัญชีเดิมอีกครั้ง ทำซ้ำจนเข้าได้หรือกด **หยุด** โดยไม่บังคับให้ผู้อื่นออกจากระบบ

เมื่อบัญชีแรกเสร็จจึงทำบัญชีถัดไป หากรหัสผ่านถูกปฏิเสธหรือบัญชีถูกล็อก จะแสดง **ต้องตรวจสอบ** ให้หยุดและแก้การตั้งค่า แทนการลองรหัสผ่านผิดซ้ำ

หลังเข้าสำเร็จและตรวจไฟล์ครบ จะไม่วนเปิดเว็บซ้ำเอง หากไม่มีเมลใหม่ก็ไม่เริ่มรอบใหม่ ถ้ามีเมลใหม่รออยู่ระหว่างทำงาน รอบถัดไปจะเว้นอย่างน้อย **4 นาที 30 วินาทีหลังจบงานที่สำเร็จ** แล้วจึงทำต่อ ไฟล์ที่โหลดไม่สำเร็จรอรอบจากเมลใหม่แทนการวนดาวน์โหลดทันที

เมื่อเปลี่ยนวัน งานค้างของวันก่อนจะไม่ถูกนำไปโหลดต่อ โปรแกรมรับเฉพาะไฟล์วันที่ปัจจุบันในรอบใหม่ การกดหยุด/เปิดใหม่เก็บรหัสเมลและเวลารอไว้ ไม่เพิ่มรอบจากเมลเดิมซ้ำ

## ตรวจไฟล์ซ้ำจาก .97

ตรวจชื่อไฟล์จริงในโฟลเดอร์ **.97 เท่านั้น** หากมีไฟล์นั้นแล้วจะข้ามโดยไม่ดาวน์โหลดหรือคัดลอก .243 ใหม่ ชื่อที่ต่างนามสกุลเป็นคนละไฟล์ เช่น `report.zip.gpg` และ `report.xlsx.gpg`

โหมด **ดาวน์โหลด .243 → คัดลอก .97** บันทึกและตรวจไฟล์ที่ .243 ก่อน แล้วอ่านไฟล์ที่ยืนยันแล้วจาก .243 ไปคัดลอกที่ .97 หากมีไฟล์ชื่อตรงกันใน .243 อยู่แล้วและ .97 ยังไม่มี จะคัดลอกไฟล์นั้นโดยไม่ดาวน์โหลดซ้ำจากเว็บ

หากบันทึก .243 ไม่สำเร็จ จะยังไม่คัดลอกไป .97 หากคัดลอก .97 ไม่สำเร็จ จะเก็บไฟล์ต้นฉบับที่ตรวจแล้วไว้ให้ลองบันทึกใหม่ ไฟล์เก่าไม่ถูกเขียนทับ หากข้อมูลต่างจากประวัติที่มีอยู่จะแจ้งให้ตรวจสอบ ไม่มีไฟล์ทดสอบสิทธิ์ tracker log หรือไฟล์ชั่วคราวในปลายทางธุรกิจ

โหมด **เก็บ .97 อย่างเดียว** ยังเลือกได้โดยไม่ใช้ .243 ระหว่างดาวน์โหลด การตั้งค่าเดิมที่เลือกเฉพาะ .243 จะเปลี่ยนเป็นโหมด .243 → .97 เพื่อเก็บสำเนาอ้างอิงด้วย

เส้นทาง KDE เดิมที่รู้จักจะเปลี่ยนเป็นโฟลเดอร์ใหม่เมื่ออ่านการตั้งค่า โดยเก็บบัญชี รหัสผ่าน เวลารอ และโฟลเดอร์อื่นที่ตั้งเองไว้ ประวัติเดิมใช้ต่อจากโฟลเดอร์ Log ใหม่

## ปุ่มและประวัติ

- **เริ่มทำงาน** เริ่มตรวจเมลใหม่ และเริ่มอัตโนมัติเมื่อเปิดโปรแกรมที่ตั้งค่าครบแล้ว
- **หยุด** หยุดรับงาน รอให้บันทึกไฟล์และออกจากบัญชีเสร็จ
- **สั่งดาวน์โหลด** จัดรอบด้วยตนเอง โดยยังรอ 4 นาที 30 วินาที
- **รายละเอียดรอบงาน** ดูผลและเหตุผลของบัญชีที่เลือก
- **ประวัติการทำงาน** ค้นหาชื่อไฟล์หรือสาเหตุ ดับเบิลคลิกเพื่อดูรายละเอียดและปลายทาง
- **แสดงรหัสผ่าน** แสดงเฉพาะตอนแก้ตั้งค่า และซ่อนอีกครั้งเมื่อเริ่ม/หยุด
- **เครื่องมือ > บันทึกไฟล์ที่ค้างอีกครั้ง** ใช้ไฟล์ที่ตรวจสอบแล้วในแคชเพื่อบันทึกปลายทางที่ค้าง ไม่เปิด KDE และไม่ดาวน์โหลดซ้ำ ให้หยุดก่อนใช้งาน

ประวัติอยู่ใน KDE_State.json, CSV เดือนละหนึ่งไฟล์ และไฟล์ล็อก ใช้โปรแกรมตรวจเมลเพียงหนึ่งตัวต่อโฟลเดอร์ประวัติเดียวกัน การตั้งค่าและแคชอยู่ที่ `%LOCALAPPDATA%\KDE Bot Download V3`

สิทธิ์ Windows/SMB ต้องอนุญาตให้อ่านและบันทึกไฟล์จริง โปรแกรมไม่สามารถข้ามสิทธิ์เหล่านี้ได้ หากเครือข่ายหรือโปรแกรมหยุดกลางการบันทึกอาจมีไฟล์ปลายทางไม่ครบ ซึ่งโปรแกรมจะเก็บไว้ให้ตรวจสอบและไม่เขียนทับอัตโนมัติ
